# Appstract Pixel 9 attribution

Original Appstract artwork and configuration: [mirrorkeydev/Appstract](https://github.com/mirrorkeydev/Appstract), Apache License 2.0. All 591 original light icons and their original SVG sources are retained in this fork.

Dashboard and additional baseline resources: [yangchoo/Appstract](https://github.com/yangchoo/Appstract), release `v5.0.6`, Apache License 2.0. The base APK is downloaded from that project's public release; its original attribution and bundled third-party resources are retained. The dashboard identifies [Donnnno/candybar-foss](https://github.com/Donnnno/candybar-foss) as its dashboard source.

This fork adds 86 original vector icons, light/dark PNG exports, 31 date variants of the calendar icon, and updated app bindings. New artwork and build tooling are distributed under this repository's Apache License 2.0.

The calendar variants use the original Appstract calendar's blue rectangle and simple stroke design. Dynamic bindings use the [Nova dynamic calendar convention](https://github.com/teslacoil/Example_NovaTheme/blob/master/DynamicCalendarIconAPI.md), which Murine Launcher supports.

The extension was prepared with assistance from OpenAI Codex. It is an unofficial community fork, not a release from the original Appstract maintainer.
